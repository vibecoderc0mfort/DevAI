# DevAI 0.1 alpha

Приложение для написания кода с собственной нейросетью **Socket 1.0**. Работает на телефоне без интернета,
ключей и аккаунтов. Есть версия для компьютера и необязательный облачный режим.

**Socket 1.0** написана и обучена с нуля (886 тысяч параметров, NumPy, без чужих весов). Это учебная модель:
по короткому английскому описанию пишет небольшие функции на Python и часто ошибается. Подробности,
данные и проверки в [socket/MODEL_CARD.md](socket/MODEL_CARD.md).

## Запуск

1. Установите Ollama с ollama.com.
2. Скачайте любую модель (один раз, нужен интернет): `ollama pull <имя модели>`.
3. Запустите DevAI (нужен Python 3.8+, больше ничего ставить не надо):

   ```
   python devai.py
   ```

Откроется браузер на http://127.0.0.1:7860. После шага 2 интернет не нужен.

Чат в терминале вместо браузера: `python devai.py --cli`

## Какую модель выбрать

В версии для компьютера модель запускает Ollama, подойдёт любая из её библиотеки (ollama.com/library).
Чем больше памяти у компьютера, тем больше модель можно взять. Выбрать конкретную: `python devai.py --model <имя>`
или переменная окружения `DEVAI_MODEL`. Если не указывать, берётся первая установленная.

## Офлайн и онлайн

- Нет интернета: всё работает, индикатор вверху показывает «Офлайн» (пустой кружок).
- Есть интернет: можно включить «Искать в интернете». DevAI находит страницы через
  DuckDuckGo и передаёт модели найденные фрагменты, источники видны под ответом.
  Поиск использует HTML-страницу DuckDuckGo и может перестать работать, если сайт её изменит.

## Что значит «без лимитов»

Нет квот, счётчика сообщений и платы за токены. Пределы задаёт ваше железо
и размер контекста (по умолчанию 8192 токена, меняется через `DEVAI_CTX`).

## Безопасность

По умолчанию сервер слушает только `127.0.0.1`, то есть доступен только с этого компьютера.
Если запустить с `--host 0.0.0.0`, интерфейс откроется для всей сети, а пароля в нём нет.

## Сборка exe и apk на GitHub

1. Создайте репозиторий на GitHub и загрузите в него все файлы этой папки (включая скрытую `.github`):

   ```
   git init
   git add .
   git commit -m "DevAI 0.1 alpha"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/devai.git
   git push -u origin main
   ```

2. Запуск сборки, любой из способов:
   - вкладка **Actions**, workflow **Build**, кнопка **Run workflow**; готовые файлы скачайте внизу страницы запуска в разделе Artifacts;
   - или `git tag v0.1.0 && git push --tags`: файлы появятся в разделе **Releases**.

3. Результат:
   - `DevAI.exe` для Windows. Модель по-прежнему запускает Ollama, её нужно поставить отдельно.
     Windows или антивирус могут показать предупреждение, потому что файл не подписан.
   - `DevAI.apk` для Android (отладочная сборка, при установке разрешите установку из неизвестных источников).

### Как работает приложение на Android

Socket 1.0 встроена в apk и устанавливается при первом запуске, интернет не нужен.

Внутри лежит движок [llama.cpp](https://github.com/ggml-org/llama.cpp) (`llama-server`, arm64, версия `b11567`).
Он запускается как процесс приложения, а интерфейс общается с ним по локальному адресу `127.0.0.1` с одноразовым ключом.

- Интерфейс: боковая панель с историей чатов, настройки (чёрная и белая тема, размер текста, стекло, анимации,
  креативность и длина ответа), заставка при запуске, кнопки «копировать» и «ещё раз» под ответом.
- Свои модели: кнопка «Выбрать свой файл .gguf» в разделе «Модели» подключает любую модель в формате GGUF.
- Облачный режим (бесплатные модели OpenRouter) выключен по умолчанию, включается в настройках.
- Приложение рисуется под системными панелями Android, внизу виден фон приложения, а не белая полоса.

Сборка движка идёт в GitHub Actions и кешируется, поэтому первая сборка apk долгая (15–30 минут),
следующие быстрые.

### Обновление приложения поверх старого

Каждая сборка подписана одним и тем же ключом (`android/app/devai.keystore`), а номер версии
растёт с каждым запуском Build. Поэтому новый `DevAI.apk` просто ставится поверх старого,
чат и ключ OpenRouter сохраняются.

Ключ лежит в открытом репозитории, это нормально для личного приложения. Если репозиторий
публичный, любой может собрать apk с такой же подписью, поэтому ставьте только свои сборки.
Если когда-нибудь решите опубликовать приложение для других, создайте новый ключ и храните его в секретах GitHub.
Если у вас стоит версия, собранная раньше, её нужно один раз удалить, потому что подпись у неё другая.
