# DevAI 0.1 alpha

Локальный ИИ-помощник для написания кода: приложения, сайты, боты, скрипты, игры.
Работает на вашем компьютере, без подписок и без лимитов на запросы.

DevAI не обучает модель с нуля. Это оболочка (чат, офлайн-режим, поиск в интернете)
над открытой моделью, которую запускает [Ollama](https://ollama.com).

## Запуск

1. Установите Ollama с ollama.com.
2. Скачайте модель (один раз, нужен интернет):

   ```
   ollama pull qwen2.5-coder:7b
   ```

3. Запустите DevAI (нужен Python 3.8+, больше ничего ставить не надо):

   ```
   python devai.py
   ```

Откроется браузер на http://127.0.0.1:7860. После шага 2 интернет не нужен.

Чат в терминале вместо браузера: `python devai.py --cli`

## Какую модель выбрать

Качество зависит от вашего железа. Список моделей: ollama.com/library.

| Оперативная память / видеопамять | Модель                  |
|----------------------------------|-------------------------|
| 8 ГБ                             | `qwen2.5-coder:3b`      |
| 16 ГБ                            | `qwen2.5-coder:7b`      |
| 32 ГБ и больше или мощная GPU    | `qwen2.5-coder:14b`, `32b` |

Выбрать другую модель: `python devai.py --model qwen2.5-coder:14b`
или переменная окружения `DEVAI_MODEL`.

## Офлайн и онлайн

- Нет интернета: всё работает, индикатор вверху показывает «Офлайн» (пустой кружок).
- Есть интернет: можно включить «Искать в интернете». DevAI находит страницы через
  DuckDuckGo и передаёт модели найденные фрагменты, источники видны под ответом.
  Поиск использует HTML-страницу DuckDuckGo и может перестать работать, если сайт её изменит.

## Что значит «без лимитов»

Нет квот, счётчика сообщений и платы за токены. Пределы задаёт ваше железо
и размер контекста (по умолчанию 8192 токена, меняется через `DEVAI_CTX`).

## Безопасность

По умолчанию сервер слушает только `127.0.0.1`, то есть доступен только с этого компьютера.
Если запустить с `--host 0.0.0.0`, интерфейс откроется для всей сети, а пароля в нём нет.

## Сборка exe и apk на GitHub

1. Создайте репозиторий на GitHub и загрузите в него все файлы этой папки (включая скрытую `.github`):

   ```
   git init
   git add .
   git commit -m "DevAI 0.1 alpha"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/devai.git
   git push -u origin main
   ```

2. Запуск сборки, любой из способов:
   - вкладка **Actions**, workflow **Build**, кнопка **Run workflow**; готовые файлы скачайте внизу страницы запуска в разделе Artifacts;
   - или `git tag v0.1.0 && git push --tags`: файлы появятся в разделе **Releases**.

3. Результат:
   - `DevAI.exe` для Windows. Модель по-прежнему запускает Ollama, её нужно поставить отдельно.
     Windows или антивирус могут показать предупреждение, потому что файл не подписан.
   - `DevAI.apk` для Android (отладочная сборка, при установке разрешите установку из неизвестных источников).

### Как работает приложение на Android

Телефон не запускает модель сам. Приложение открывает DevAI, который работает на вашем компьютере:

1. На компьютере: `DevAI.exe --host 0.0.0.0` (или `python devai.py --host 0.0.0.0`).
   В консоли появится адрес вида `192.168.1.5:7860`.
2. Телефон и компьютер должны быть в одной Wi-Fi сети. Введите адрес в приложении.

У интерфейса нет пароля, поэтому используйте это только в доверенной сети (домашний Wi-Fi).
Сменить адрес можно кнопкой «Сменить сервер» внизу чата.
