# Socket 1.0

Собственная учебная нейросеть проекта DevAI. Написана и обучена с нуля: код трансформера, обратный проход
и обучение на NumPy, без готовых весов и без фреймворков. Работает в приложении прямо на телефоне.

## Что умеет
По короткому описанию **на английском** дописывает небольшую функцию на Python:

```
### Task: Close the connection.
### Code:
def __init__(self, other):
    return other
```

Это пример настоящего ответа, и он показывает уровень: модель хорошо знает форму Python-кода
(`def`, `self`, `isinstance`, `return`), но задачи в большинстве случаев не решает. Это учебный проект,
а не помощник для работы. Русский язык и обычный диалог она не понимает.

## Устройство
| | |
|---|---|

| Архитектура | Llama-подобный трансформер: RMSNorm, RoPE, SwiGLU, 4 слоя, 4 головы, ширина 128, общие веса входа и выхода |

## Обучение
- Данные: 7 992 пары «первое предложение docstring → код функции» из открытых Python-проектов
  (список и лицензии в `DATA_SOURCES.md`), около 2,1 млн символов. Ещё 163 примера отложены для проверки.
- Оптимизатор AdamW, косинусное снижение скорости, обрезка градиента, три этапа (из-за остановок среды),
  всего 2 905 шагов и около 6 млн символов (примерно 2,8 прохода по данным).
- Оборудование: одно ядро процессора, около полутора часов.
- Ошибка на отложенных примерах: 0,90 (в среднем 0,90 нат на символ, начало обучения 5,6).

## Проверки
- Градиенты обратного прохода сверены с численными (`gradcheck.py`): расхождение 2·10⁻⁷.
- Файл GGUF загружен настоящим llama.cpp (версия b11567): жадная генерация совпала с моей реализацией
  символ в символ на трёх запросах, включая остановку по символу конца ответа.

## Ограничения и этика
- Может писать неверный, бессмысленный и зацикленный код. Всегда проверяйте результат.
- Обучена на ASCII-тексте и только на Python. Другие языки программирования не знает.
- Лицензия на веса и код не выбрана: решение за автором проекта.
