# Данные для обучения Socket 1.0

Модель обучена только на открытом Python-коде с разрешающими лицензиями. Из каждого проекта взяты
функции с docstring (первое предложение стало описанием задачи, остальное кодом). Тесты, документация
и примеры исключены, повторы убраны, оставлен только ASCII-текст.

| Источник | Лицензия |
|----------|----------|
| Стандартная библиотека Python (CPython) | PSF License |
| Django | BSD-3-Clause |
| Flask, Click, Jinja, Werkzeug | BSD-3-Clause |
| Requests | Apache-2.0 |
| HTTPX, Starlette | BSD-3-Clause |
| pytest, attrs, more-itertools | MIT |
| tqdm | MIT и MPL-2.0 |
| Gunicorn | MIT |

Исходный код этих проектов в репозиторий не входит. Скрипты `data.py` и `train.py` позволяют повторить
подготовку данных и обучение на любом наборе Python-проектов.
